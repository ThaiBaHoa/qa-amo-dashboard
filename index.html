Definitions & Terminology
Report Status
Open
Report is being processed, not yet due or has no target date. The assignee must carry out corrective action.
Overdue
Report has passed its target date but has not been closed. Must be prioritised immediately. Further classified by CAT I/II/III.
On-time Closed
Report closed on or before its target date. Applies only to forms that have a target date (CAR, MCAR, PAVOI…).
Lately Closed
Report was closed after its target date. Root-cause analysis is recommended to improve the on-time rate.
Closed
Report closed with no target date (Surveillance Report, Aircraft Inspection…). Not counted in the on-time rate.
Overdue Category (CAT)
CAT I
Overdue ≤ 30 days — Monitor closely and follow up within the week.
CAT II
Overdue 30–60 days — Escalate to senior management and request a corrective action plan.
CAT III
Overdue > 60 days — Critical. Report immediately to senior leadership and take urgent action.

KPI Definitions
On-time Rate
= On-time Closed ÷ (On-time Closed + Lately Closed) × 100%. Calculated only on forms with a target date. Target: ≥ 70%.
Repetitive Rate
= Number of repeated findings ÷ Total findings × 100%. Findings marked "Repetitive = Yes" in the form. Target: ≤ 10%.
Days to Due
Days remaining until the target date (positive = within deadline, negative = overdue). Calculated from today.

Page Guide
📊Overview
Full QA AMO summary dashboard. The Year filter at the top lets you view data by year (defaults to current year).
• 6 KPI cards: Total / Open / Overdue / On-time / Lately / Closed
• Donut chart: Distribution by status
• Findings by Month: Monthly trend — filter further by year using the dropdown in the top-right corner
• Top Forms: Forms with the most findings — filter by All/Open/Overdue
• Form table: Open/Overdue/Closed totals per form type
• 4 metric cards: Open+Overdue / On-time Rate / CAT III / Repetitive
📋Open Reports
List of all reports currently in Open or Overdue status.
• Filter by Status (All/Open/Overdue), Form Type, Year, or free-text search
• Days to Due column: green = plenty of time, orange = approaching deadline, red = overdue
• Click any column header to sort ascending/descending
• ⚠ Yes in the Repetitive column = this finding has occurred before
⚠️Overdue
Shows only overdue reports, analysed by CAT level.
• 3 KPI cards: CAT I / CAT II / CAT III with exact counts
• By CAT chart: Overdue distribution by severity
• By Form chart: Which forms have the most overdue items
• Filter by Form Type and CAT level
📈KPI Charts
KPI trend analysis over time.
• On-time Rate by Month: 70% target line — track which months pass or fail
• Repetitive Rate by Month: Trend of repeated findings
• Cumulative YTD: Year-to-date cumulative finding count
• On-time Rate by Year: Year-on-year performance comparison
• Repetitive Rate by Year: Year-on-year repetitive finding trend
📄All Forms
Complete list of all QA AMO reports across every status.
• Filter by Status, Form Type, Year, or search
• MNT No column: Audit number that this report belongs to
• Audit Ref column: Audit reference number (Audit Ref. No)
• Audit Title column: Name of the audit — click the column header to sort
🔍PAVOI Detail
Shows only PAVOI forms with full verification details.
• Request For Verification: Content of the verification request for implementation
• Report Reference: Original report number that the PAVOI is tracking (e.g. MCAR-0086)
• Verification Result: Satisfactory = passed / Not Satisfactory = not yet passed
• Department: Department responsible for implementation
📅Audit Plan
QA AMO audit schedule and history from Galileo Planner.
• 6 KPI cards: Total / Internal Audit / Inspection / Closed / In Progress / Scheduled
• Filter by Type (📋 Internal Audit / 🔍 Inspection), Status, Year
• Findings column: Number of reports generated from that audit
• Open/Overdue column: Open/overdue finding count for that audit
• Scheduled audits = not yet started (future plans)
📄
Export Reports
📄 Export PDF
Export report as a PDF for printing or emailing.

PDF contents include:
• VietJet red header with report title
• 6 KPI cards
• 3 charts (Status, Top Forms, Monthly)
• Overdue by CAT analysis table
• Summary table by Form type
• Finding details (up to 200 records)

PDF is automatically paginated to A4.
📊 Export Excel
Export a .xlsx file for further analysis in Excel.

Excel file has 3 sheets:
• Sheet 1 — KPI Summary: KPI totals and Overdue CAT breakdown
• Sheet 2 — Form Summary: Open/Overdue/On-time/Lately/Closed per form type
• Sheet 3 — Detail Data: All findings with full field data

Filename is auto-generated with the report title and export date.
🔧 How to use the Export page:
Step 1: Open Export Reports from the left sidebar
Step 2: Choose a filter type from the "Filter by" dropdown:
  • By Month/Year → select a specific Year and Month
  • By Quarter/Year → select a Year and Quarter (Q1–Q4)
  • By Form Type → select a specific form (MCAR, PAVOI…)
  • All → no filter, loads all data
Step 3: Review the report preview on the page
Step 4: Click 📄 PDF or 📊 Excel to download
